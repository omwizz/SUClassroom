# Referencias UI — SUClassroom

Estas imágenes son referencias visuales para definir estilo, composición, componentes y experiencia de usuario de SUClassroom.

## Uso permitido para Codex

Codex debe usarlas únicamente como referencia de:

- Layout de dashboard.
- Sidebar lateral.
- Topbar.
- Cards de métricas.
- Tablas.
- Modales.
- Formularios.
- File manager.
- Reportes.
- Analítica.
- Calendario.
- Mensajes.
- Tasks.
- Landing pública.
- Catálogo de cursos.
- Cards de cursos.
- Estados visuales.
- Badges.
- Botones.
- Estilo dark mode.
- Glassmorphism moderado.
- Diseño SaaS moderno.

## Lo que NO debe hacer Codex

- No copiar textos exactos.
- No copiar nombres de usuarios.
- No copiar marcas como midudev.
- No copiar logos.
- No copiar precios.
- No copiar colores exactos si no encajan con SUClassroom.
- No usar fechas falsas.
- No crear una réplica literal.
- No usar imágenes como assets finales del producto.

## Dirección visual deseada

### Landing pública

Inspirarse en las imágenes tipo academia/cursos:
- Fondo oscuro elegante.
- Hero fuerte.
- Cards de cursos.
- CTA visible.
- Secciones claras.
- Planes o beneficios si aplica en fase futura.
- Estilo moderno y tecnológico.

### Dashboard administrador

Inspirarse en las imágenes de admin panel oscuro:
- Sidebar fija.
- Topbar.
- Cards de métricas.
- Gráficos.
- Tablas.
- Modales.
- File manager.
- Reportes.
- Usuarios.
- Configuración.
- Estética dark glassmorphism profesional.

### Dashboard alumno

Debe ser más claro, motivador y orientado al progreso:
- Cursos disponibles.
- Progreso.
- Próximo paso.
- Entregables.
- Feedback.
- Asesorías.

### Dashboard mentor

Debe priorizar productividad:
- Entregables pendientes.
- Alumnos asignados.
- Evaluaciones.
- Feedback.
- Agenda.

### Dashboard institución

Debe verse corporativo:
- Cohortes.
- Participantes.
- Avance.
- Reportes.
- Impacto.

## Regla principal

SUClassroom no debe verse como una copia de estas referencias. Debe usar las imágenes como inspiración visual para construir una identidad propia.
